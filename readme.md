# Lake Okeechobee Wading Bird Monitoring

This repository contains all code and data used to produce the tables and figures presented in Wading Bird Monitoring annual reports (W912HZ-24-2-0031) submitted to the U.S. Army Corps of Engineers. Data are analyzed on a yearly basis. Each folder is labeled with the corresponding report year and contains all relevant code and data files needed to reproduce the results presented in that year’s annual report. For additional details, see the README file in each associated folder.
